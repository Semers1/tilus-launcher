# Tilus Launcher

Лаунчер Minecraft для игроков сервера [tilus.ru](https://tilus.ru). Основан на
[Modrinth App](https://github.com/modrinth/code) v0.21.10 (коммит `ff971f6`) и, как и он,
распространяется по лицензии GPL-3.0.

## Скачать

**[TilusLauncher-setup.exe](https://github.com/Semers1/tilus-launcher/releases/latest/download/TilusLauncher-setup.exe)**,
последняя версия для Windows 10 и 11 (64 бит). Все версии и списки изменений лежат в
[Releases](https://github.com/Semers1/tilus-launcher/releases).

### Если Windows пишет «Система Windows защитила ваш компьютер»

Установщик не подписан платным сертификатом, поэтому при первом запуске фильтр SmartScreen
может показать синее окно. Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.
Обновления лаунчер скачивает и ставит сам, и это окно больше не появится.

## Чем отличается от Modrinth App

- Своё имя, иконки и интерфейс на русском по умолчанию; можно переключить на украинский или
  казахский (казахский переведён частично).
- Вход по нику без лицензии: UUID совпадает с офлайн-сервером. Вход через Microsoft остался.
- Убраны Modrinth Hosting, реклама, опросы, аналитика и отправка отчётов об ошибках.
- Стеклянное окно с цветом под иконку текущей сборки; вода в буквах TILUS показывает загрузку.
- Панель серверов tilus.ru вместо новостей Modrinth: онлайн, пинг, кнопка «Играть».
- Автонастройка под железо: память и флаги Java, графика, дискретная видеокарта.
- Исправлены две ошибки Modrinth App, из-за которых лаунчер грузил процессор в простое.
- Обновления приходят из Releases этого репозитория.

Моды и сборки по-прежнему ищутся и скачиваются с modrinth.com. Tilus Launcher не связан с
Modrinth, Mojang или Microsoft.

## Сборка

Нужны Windows, [Rust](https://rustup.rs) (версия берётся из `rust-toolchain.toml`),
Node.js 24 и pnpm (через `corepack enable`).

```bash
cp packages/app-lib/.env.prod packages/app-lib/.env
pnpm install
cd apps/app
SQLX_OFFLINE=true pnpm tauri build --bundles nsis
```

Такая сборка не подписывает файл обновления. Релизы собираются с
`--config tauri.release.conf.json` и ключом из переменной `TAURI_SIGNING_PRIVATE_KEY`, весь
выпуск описан в [scripts/tilus/release.mjs](scripts/tilus/release.mjs). Собранный у себя
лаунчер проверяет обновления этого репозитория; чтобы раздавать свою версию, создайте свой
ключ (`pnpm tauri signer generate`) и пропишите его открытую часть и свой адрес в
`plugins.updater` файла `apps/app/tauri.conf.json`.
