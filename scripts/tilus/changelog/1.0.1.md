Первая публичная версия Tilus Launcher, лаунчера Minecraft для игроков tilus.ru на основе Modrinth App 0.21.10.

- Интерфейс на русском по умолчанию, можно переключить на украинский или казахский.
- Вход по нику без лицензии; вход через Microsoft тоже работает.
- Панель серверов tilus.ru: онлайн, пинг и кнопка «Играть».
- Автонастройка памяти, Java и графики под твой компьютер.
- Без рекламы, опросов и аналитики.
- Лаунчер сам проверяет обновления и ставит их при закрытии.
